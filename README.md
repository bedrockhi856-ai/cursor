# Hi App

A clean and visually appealing Flutter app that simply says "Hi" with a smooth fade-in animation.

## Getting Started

1. **Install Flutter**: [Flutter installation guide](https://flutter.dev/docs/get-started/install)
2. **Get dependencies:**
   ```
   flutter pub get
   ```
3. **Run the app:**
   ```
   flutter run
   ```

## Features
- Minimalist, modern design
- Smooth fade-in animation
- Beautiful gradient background
